# bauhouzz.ru — статический сайт

Сайт-портфолио дизайнера интерьера Ольги Бауриной. Чистый статический сайт:
HTML, CSS и немного JavaScript. Без базы данных, без CMS и без сборщика —
достаточно положить файлы в репозиторий.

## Что где лежит

```
index.html          главная: портфолио, услуги, об авторе, контакты
prices.html         услуги и цены, этапы работ
consent.html        политика конфиденциальности
404.html            страница «не найдено»
projects/*.html     страницы проектов (квартиры, дома, общественные)
art/*.html          арт-проекты и конкурсные работы
assets/css/main.css оформление
assets/js/main.js   меню, появление блоков, лайтбокс
assets/img/...      изображения, по одной папке на проект
content/*.json      тексты и структура портфолио
tools/build.py      генератор страниц
raw/                исходные файлы изображений (в репозиторий не входит)
```

## Как добавить проект в портфолио

1. Положить фотографии в папку проекта, например `assets/img/newproject/`,
   имена по порядку: `01.jpg`, `02.jpg`, …
   Либо положить исходники в `raw/` и прописать их в `content/projects.json` —
   генератор сам уменьшит и переименует файлы.
2. Открыть `content/projects.json` и добавить объект:

```json
{
  "slug": "newproject",
  "section": "projects",
  "order": 9,
  "title": "ЖК Пример",
  "subtitle": "Двухкомнатная квартира, 64 м²",
  "kind": "Квартира",
  "year": "2025",
  "intro": "Короткое описание проекта в одно-два предложения.",
  "cover": null,
  "groups": [
    { "caption": "Гостиная", "images": [] },
    { "caption": "Спальня", "images": [] }
  ]
}
```

3. Пересобрать страницы:

```bash
python3 tools/build.py
```

4. Закоммитить и отправить:

```bash
git add -A
git commit -m "Портфолио: ЖК Пример"
git push
```

Через минуту сайт обновится. Никакой админки для этого не нужно.

## Локальный просмотр

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000`.

## Варианты размещения на GitHub Pages

| Что | Репозиторий | Адрес |
|---|---|---|
| проект в личном аккаунте | `andrew/bauhouzz` | `https://andrew.github.io/bauhouzz/` |
| проект в организации | `bauhouzz/bauhouzz` | `https://bauhouzz.github.io/bauhouzz/` |
| корневой сайт организации | `bauhouzz/bauhouzz.github.io` | `https://bauhouzz.github.io/` |
| свой домен (любой из вариантов) | — | `https://bauhouzz.ru/` |

Корневой сайт удобнее: ссылки вида `/assets/...` и `/projects/...` работают
без префикса, а при переезде на домен ничего не меняется.

## Публикация на GitHub Pages

Одной командой:

```bash
./deploy.sh                          # bauhouzz в личном аккаунте
./deploy.sh bauhouzz/bauhouzz.github.io   # корневой сайт организации
```

Скрипт при необходимости попросит авторизоваться в GitHub, создаст публичный
репозиторий, соберёт страницы с нужным префиксом пути, отправит файлы и
включит Pages.

Дальше — вручную, если нужно:

Сайт раздаётся из ветки `main`, папка — корень репозитория.
В настройках репозитория: **Settings → Pages → Source: Deploy from a branch,
Branch: main / (root)**.

Адрес по умолчанию: `https://<username>.github.io/<repo>/`.

### Свой домен

1. В `Settings → Pages → Custom domain` указать `bauhouzz.ru`.
2. У регистратора домена создать записи:

```
A     @    185.199.108.153
A     @    185.199.109.153
A     @    185.199.110.153
A     @    185.199.111.153
CNAME www  <username>.github.io.
```

3. Дождаться выпуска сертификата и включить `Enforce HTTPS`.

Файл `CNAME` в корне репозитория создаётся автоматически при указании
домена в настройках **репозитория** (`/settings/pages`), а не организации.
Он уже закоммичен и содержит `bauhouzz.ru` — удалять его нельзя, иначе
привязка домена слетит.

## Требования

Только Python 3 и Pillow — для генератора страниц:

```bash
python3 -m pip install --user pillow
```

Сам сайт ничего не требует: это статические файлы.
